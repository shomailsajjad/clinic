# See the clinic application

These are screenshots captured from the running application, using invented
patients, sample accounts and illustrative prices. They are real application
screens, not design mockups. No installation or hosting payment is needed to
view this page. Sign in to GitHub if the repository requires it.

This is a visual walkthrough, not an interactive website. Booking, token
generation, payments/refunds, diagnostic reports and backups are not yet built.
